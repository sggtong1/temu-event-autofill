# Temu活动价格自动填充工具

一个Chrome浏览器插件，用于自动填充Temu活动页面的价格信息。

## 功能特性

### 🎯 核心功能
- **自动价格填充**: 根据货号自动匹配并填充活动申报价格
- **智能识别**: 自动识别页面中的货号和价格输入框
- **一键操作**: 点击按钮即可批量填充所有匹配的价格

### 📊 数据管理
- **预设价格数据**: 支持货号、活动价格、成本价格、备注等信息
- **数据导入导出**: 支持JSON和CSV格式的数据导入导出
- **搜索过滤**: 快速查找特定货号的价格数据
- **批量编辑**: 支持添加、编辑、删除价格数据

### ⚙️ 设置选项
- **自动填充开关**: 可控制是否启用自动填充功能
- **通知设置**: 可选择是否显示填充通知
- **填充延迟**: 可设置填充操作的延迟时间

## 安装方法

### 1. 开发者模式安装
1. 打开Chrome浏览器
2. 访问 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本插件文件夹

### 2. 打包安装
1. 在开发者模式下点击"打包扩展程序"
2. 选择本插件文件夹生成.crx文件
3. 将.crx文件拖拽到Chrome扩展程序页面安装

## 使用说明

### 1. 设置价格数据
1. 点击浏览器工具栏中的插件图标
2. 在"数据管理"标签页中添加价格数据：
   - 货号：如 `92-BK-15`
   - 活动价格：如 `48.24`
   - 成本价格：如 `30.00`（可选）
   - 备注：产品描述（可选）

### 2. 导入现有数据
1. 切换到"导入导出"标签页
2. 点击"选择文件导入"
3. 支持JSON和CSV格式：
   ```json
   [
     {
       "itemNumber": "92-BK-15",
       "activityPrice": 48.24,
       "costPrice": 30.00,
       "note": "便携式水冷风扇-黑色"
     }
   ]
   ```

### 3. 自动填充价格
1. 访问Temu活动页面：`https://agentseller.temu.com/activity/marketing-activity/detail-new`
2. 页面加载完成后会显示"💰 自动填充活动价格"按钮
3. 点击按钮即可自动填充所有匹配的价格

### 核心功能
- **内容脚本**: 在Temu活动页面注入价格填充按钮和逻辑
- **数据存储**: 使用Chrome Storage API存储价格数据
- **页面识别**: 智能识别货号和价格输入框
- **数据匹配**: 根据货号精确匹配价格数据

## 注意事项

1. **页面兼容性**: 插件针对Temu活动页面设计，其他页面不会激活
2. **数据安全**: 所有数据存储在本地，不会上传到服务器
3. **更新维护**: 如Temu页面结构变化，可能需要更新插件
4. **权限说明**: 插件仅访问Temu相关页面，不会影响其他网站

## 故障排除

### 常见问题
1. **按钮不显示**: 确保在正确的Temu活动页面，刷新页面重试
2. **价格未填充**: 检查货号是否完全匹配，确认数据已正确设置
3. **数据丢失**: 数据存储在本地，清除浏览器数据会丢失

### 调试方法
1. 按F12打开开发者工具
2. 查看Console标签页的错误信息
3. 检查Network标签页的网络请求
